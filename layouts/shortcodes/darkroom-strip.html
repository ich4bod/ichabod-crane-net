Choose the spacing

Time = first exposure × 2^(band index × stop step). Band indices start at zero.

  1. Band 1: 8.00 seconds.8 seconds
  2. Band 2: 11.31 seconds.11.31 seconds
  3. Band 3: 16.00 seconds.16 seconds
  4. Band 4: 22.63 seconds.22.63 seconds
  5. Band 5: 32.00 seconds.32 seconds

These bars measure exposure time, not the darkness of photographic paper. The light is assumed constant; this does not predict a print.

Build the strip

Expose every uncovered band, then cover the leftmost one. Each press adds only the time needed for the next target.

Give one place more light

Each press adds one first-exposure amount. ‘Here’ gives extra light to one band; ‘everywhere else’ holds that band back. These are timing demonstrations, not paper-density predictions.
